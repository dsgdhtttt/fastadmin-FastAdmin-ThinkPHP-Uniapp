# fastadmin沃德商协会管理系统源码 FastAdmin+ThinkPHP+Uniapp

源码获取：ym7k.com/19777/

## 技术架构

- 后端：FastAdmin + ThinkPHP
- 移动端：UniApp，可编译微信小程序、H5
- 后台权限体系完善，支持自定义底部导航、首页装修、菜单配置，代码开放，方便二次定制开发WdAdmin

## PC 后台核心管理模块

- 会员管理：会员列表、入会类型、行业分类、会员风采、推广会员
- 数据统计、权限管理、插件管理
- 商会内容：资讯文章、商会相册
- 活动管理：活动发布、报名记录、活动核销、活动接龙
- 供需商圈管理：商机、合作、项目、融资帖子审核管理
- 商城管理：商品上下架、订单管理
- 会费管理：会费规则配置、缴费记录、自动催缴
- 系统设置：首页自定义装修、底部导航配置、字典、缓存清理等（截图可见可视化导航配置面板）

## 小程序端功能（前端展示）

✅ 首页：商会介绍轮播、会员申请入口、功能图标矩阵
✅ 会员服务：证书查询、商会相册、会员风采、会员通讯录
✅ 内容板块：文章资讯、商会活动、活动接龙、活动核销签到
✅ 交易板块：商会商城、商品下单
✅ 供需商圈（核心亮点）：会员自主发布商机、合作、项目、融资信息，支持配图、浏览统计、一键联系发布人，会员资源对接
✅ 运营工具：问卷调查、需求建议、消息订阅
✅ 收费模块：在线会费缴纳，支持按会员等级设置不同会费标准
✅ 分销推广：推广会员，发展新会员
✅ 底部 tab：首页 / 会员 / 商城 / 供需 / 我的，后台可视化修改图标、名称、排序、显隐

## 业务亮点

1. **供需商圈**：会员自由发布商业信息，分类【商机 / 合作 / 项目 / 融资】，支持点赞分享、联系洽谈，打造协会内部资源对接池
2. **活动全流程**：线上报名、接龙收集、线下扫码核销，活动结束可自动生成电子证书
3. **会费数字化**：自定义会费方案，自动生成账单、消息提醒催缴，对账省心
4. **灵活装修**：首页图标、底部导航全部后台可视化配置，不用改前端代码
5. **多端适配**：微信小程序 + H5 双端，一套 uniapp 代码
6. **权限隔离**：会长、管理员、普通会员权限区分，通讯录、相册可设置查看权限
7. 私有化源码交付，可自主部署服务器，数据自主掌控FastAdmin

## 适用客户

各行各业商会、企业家协会、异地商会、行业协会、校友会、工商联团体。
